# ParsStove Canada

Marketing website for ParsStove Canada, featuring high-efficiency stoves, fireplaces, professional installation, and project consultation.

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
npm run build
```

The site uses Next.js, vinext, Motion, and Cloudflare-compatible output.

Deploy the validated build to the connected Cloudflare account with:

```bash
npm run deploy:cloudflare
```
